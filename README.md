# Computer Networks Project

This repository contains the deliverables for the CSE 421 computer networks project. The project includes a Cisco Packet Tracer network implementation, its subnetting and addressing plan, configuration commands, assumptions, and the team work distribution.

## Project Files

| File | Description |
| --- | --- |
| `CSE421.PROJECT.final(2).pkt` | Cisco Packet Tracer topology and device configuration for the completed network project. |
| `VLSM Tree + Address Table + Configuration Commands + List of any assumptions.pdf` | Project documentation containing the VLSM subnetting tree, IP address table, configuration commands, and stated assumptions. |
| `Work Distribution.docx` | Record of how the project work was distributed among team members. |

## How to Review the Project

1. Open the `.pkt` file with Cisco Packet Tracer.
2. Review the topology, device interfaces, addressing, and configured services.
3. Use the PDF to verify the VLSM calculations, address assignments, configuration commands, and assumptions.
4. Consult the work distribution document for contribution details.

## Scope

The repository is intended for academic review and project submission. The PDF is the authoritative reference for the project's documented addressing decisions, configuration commands, and assumptions.
